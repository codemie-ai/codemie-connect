# Spec: CodeMie Installer — Electron → Tauri v2 migration

**Date:** 2026-06-11
**Slug:** tauri-macos-installer
**Status:** Approved (design approved interactively)

## Goal

Re-implement the CodeMie macOS installation wizard (currently Electron, ~550 MB DMG) on **Tauri v2** so the shareable DMG is **< 20 MB**, while preserving the existing UX and install behavior exactly. macOS only. Unsigned / un-notarized DMG (no signing required). Greenfield project at `/Users/Vadym_Vlasenko/AI/projects/codemie-claude-installer-macos-tauri`. Reference app: `/Users/Vadym_Vlasenko/AI/projects/codemie-claude-installer-macos`.

## Non-goals

- Code signing / notarization.
- Changing the install plan (`config/steps.yaml`) or step semantics.
- A notable UI redesign. Scope is **parity + light polish** only.
- Auto-running the real (destructive) install flow as a test.
- Windows/Linux support.

## Architecture — Option B (locked)

Keep the **orchestration brain in frontend JS**; port only the system-facing modules to Rust.

- **Frontend (vanilla ES modules, no bundler):** `engine.js`, `handlers.js`, `models.js` copied near-verbatim from the Electron renderer's main-process logic. The approval gate stays a JS `Promise`-resolver (`engine._gate = { resolve }`) — **no** Rust `oneshot` port. Handlers replace Node module calls with Tauri `invoke()`/`listen()`.
- **Backend (Rust/Tauri v2):** thin `#[tauri::command]` layer porting the 8 Node system modules. Backend→frontend push via `app.emit("engine:*", payload)`.
- **No `start` Rust command.** The wizard is driven by the JS engine calling granular Rust commands. `get_steps` remains (steps.yaml lives in Rust, embedded via `include_str!`).

**Rationale:** reuses ~400 lines of already-tested JS, eliminates the highest-risk item (async approval-gate port), keeps the migration surgical. Business logic in the webview is acceptable for a local installer with no untrusted input.

## IPC surface (1:1 with technical-analysis §8)

**invoke — queries:** `get_steps`, `get_logo_path`.

**invoke — actions / primitives** (called by JS handlers): `approve`, `ignore`, `set_unattended`, `open_log`, `close_app`, `set_window_height`, `pty_input`, `pty_resize`, `run_capture`, `run_stream`, `run_fresh_env`, `check_git`, `check_node`, `check_npm`, `check_codemie`, `git_binary_path`, `node_binary_path`, `latest_lts_node_version`, `node_pkg_url`, `install_node`, `install_git_clt`, `resolve_shell_path`, `persist_to_zprofile`, `download_file`, `spawn_pty`.

- `approve`/`ignore`/`set_unattended` operate on JS engine state — under Option B they may be pure-JS (no Rust command) OR thin no-op Rust commands; **chosen: pure JS** (engine lives in the webview, so `approve()` resolves the JS gate directly). Only system-touching calls cross into Rust.
- `run_stream` streams output lines back via an `engine:cmd-line` event carrying a call id (Tauri commands cannot take a Node-style per-line callback). The JS `runStream` wrapper subscribes to that event for the matching id and resolves on an `engine:cmd-done` event.

**emit — events (names + shapes unchanged):** `engine:status-change`, `engine:subtitle-change`, `engine:spinner-start`, `engine:approval-needed`, `engine:download-progress`, `engine:terminal-line`, `engine:substep-activate`, `engine:fatal`, `engine:complete`, `engine:pty-open`, `engine:pty-data`, `engine:pty-exit`. Plus internal `engine:cmd-line` / `engine:cmd-done` for `run_stream`.

## PTY approach (highest risk)

`portable-pty`: open pair with `PtySize{rows,cols}` → `CommandBuilder::new("/bin/zsh")` args `["-lc", cmd]`, env `HOME`, augmented `PATH`, `TERM=xterm-256color` → spawn child from slave → store `PtyHandle{ master, child }` in `Mutex<Option<…>>` managed state.

- **Dedicated `std::thread`** (NOT a tokio task) pumps the blocking reader; each chunk is **base64-encoded** and emitted as `engine:pty-data` to avoid UTF-8/ANSI-escape corruption when a multi-byte sequence splits across 4096-byte reads. `terminal.js` base64-decodes before `term.write()`.
- A second thread waits on child exit and emits `engine:pty-exit { code }`.
- `pty_input` writes to the master; `pty_resize` calls `master.resize()`.

## Build / packaging

- Scaffold via official `cargo tauri init` to get the **current-version** skeleton (config + capabilities format), then port logic in.
- `tauri.conf.json`: productName "CodeMie Installer", identifier `com.epam.codemie.installer`, version `2.0.0`; window 900×600, `resizable:false`, `backgroundColor:#0b0d14`, title "CodeMie Installation Wizard"; `withGlobalTauri:true`; CSP `default-src 'self'; img-src 'self' asset: data:; style-src 'self' 'unsafe-inline'; script-src 'self'`; `bundle.targets:["dmg"]`, `macOS.signingIdentity:null`.
- `Cargo.toml` `[profile.release]`: `lto=true, codegen-units=1, strip=true, panic="abort"`, `opt-level="z"` (size).
- Icons: `cargo tauri icon assets/codemie-logo.svg`.
- Dev builds: native arch. Final shareable DMG: `cargo tauri build --target universal-apple-darwin` (both Rust targets added).

## Light polish ("cool") — strictly additive, parity-first

macOS window vibrancy/translucency (only if cheap & CSP-safe), smoother sprite easing, tidy CSS transitions. Each is gated so it never blocks parity; dropped if it fights CSP/opaque background. Headline cool = the 550MB→<20MB drop + native snappiness.

## Testing / verification (non-destructive boundary — agreed)

- **Rust unit tests** (`#[test]`, RED→GREEN) port the 7 JS unit tests for pure logic: inspector version parsing + codemie exit-127 heuristic; pathman dedupe/missing/merge + `persist_to_zprofile` idempotency; installer `node_pkg_url` + `latest_lts_node_version` (mocked); steps YAML parse + defaults; logger line formatting + tag mapping; runner exit-code propagation against real shell.
- **No forced TDD** on Tauri glue, PTY thread-emit, window resize — verified via build + launch + smoke.
- **Smoke modes ported** (env-gated in `main.rs`):
  - `CODEMIE_PROBE_SMOKE`: run detection-only steps (`1.1,1.1.1,1.2,1.2.1,1.3`) unattended, print `PROBE_RESULT <id:status …>` + `PROBE_DONE`, quit.
  - `CODEMIE_SMOKE`: confirm renderer booted (step row count, title, canvas present) + benign PTY echo (`echo PTY_SELFTEST_OK; exit 0` → `sawMarker`), print `SMOKE_OK`, quit. Optional `CODEMIE_SHOT` screenshot path; `CODEMIE_SMOKE_MS` delay override.
- **Size gate:** final DMG asserted < 20 MB.
- **Real destructive install never auto-run** (npm -g, codemie setup/install, sudo pkg, xcode-select, ~/.zprofile writes) — left to the user (manual / VM).

## Phasing (single run, 4 milestones)

1. **Scaffold + risk-kill:** install Rust toolchain + tauri-cli; `cargo tauri init`; copy UI verbatim with stubbed commands; build a launching DMG; **measure size < 20MB**.
2. **Non-PTY commands:** port runner/inspector/installer/pathman/downloader/logger/steps to Rust + Rust unit tests; rewire JS handlers to `invoke`; `CODEMIE_PROBE_SMOKE` green.
3. **PTY integration:** `pty.rs` + base64 path + `terminal.js` decode; benign-echo PTY smoke green.
4. **End-to-end wizard:** approval gate, log-panel window resize, sprite, fatal overlay all wired; `CODEMIE_SMOKE` green; **universal DMG** built + final verification + size gate.

## Success criteria

- `cargo tauri build` produces a DMG that launches and renders the wizard UI (parity with the Electron app).
- Universal DMG **< 20 MB**.
- `CODEMIE_PROBE_SMOKE` and `CODEMIE_SMOKE` both pass.
- All ported Rust unit tests green.
- Rust + JS clean (no warnings-as-errors failures; `cargo clippy` clean on our code).
- The destructive install path is fully wired (verifiable by hand) but not auto-executed.
